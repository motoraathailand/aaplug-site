AA Plug 2 — Privacy Policy

Effective 2026-11-12

English · 한국어 · ภาษาไทย · 中文 · हिन्दी

English

AA Plug 2 reads and analyzes the app project you connect only inside your browser. Files, analysis results and generated assets are never sent to or stored on any server.

If you enter a public GitHub URL, your browser downloads the public files directly from GitHub. We never ask for tokens or passwords. Progress and your language choice are kept only in this device’s browser storage (localStorage) so you can continue later, and are removed when you tap “Connect a new app” or clear browser data.

Contact: aaplug.com

한국어

AA Plug 2는 연결한 앱 프로젝트 파일을 사용자의 브라우저 안에서만 읽고 분석합니다. 파일, 분석 결과, 만들어진 자료를 어떤 서버로도 보내거나 저장하지 않습니다.

GitHub 공개 저장소 주소를 넣으면 브라우저가 GitHub에서 공개 파일을 직접 받아옵니다. 토큰이나 비밀번호는 묻지 않습니다. 진행 상황과 고른 언어는 다음에 이어서 할 수 있도록 이 기기의 브라우저 저장소(localStorage)에만 보관되며, “새 앱 연결하기”를 누르거나 브라우저 데이터를 지우면 삭제됩니다.

문의: aaplug.com

中文

AA Plug 2 只在你的浏览器内读取和分析你连接的应用项目。文件、分析结果和生成的素材绝不会发送或存储到任何服务器。

如果你输入公开的 GitHub 地址，浏览器会直接从 GitHub 下载公开文件。我们绝不会索取令牌或密码。进度和你选择的语言只保存在本设备的浏览器存储（localStorage）中，方便你下次继续；点击“连接新应用”或清除浏览器数据即会删除。

联系： aaplug.com
