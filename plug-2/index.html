AA Plug 2

Takes an app you already built to Google Play and the App Store. Connect it once, then you only pick and approve — nothing is submitted automatically.

Web version ↗ How to connect ↓

How to connect

Ask in a chat EASIEST

Add an MCP server. Name AA Plug 2, command npx, arguments -y aaplug2-mcp

Or add it yourself

  1. Connect apps→Add a custom connector (sidebar)
  2. Type
    Command
    Command
    npx
    Arguments
    -y aaplug2-mcp

Not in the Grok Bot Marketplace yet. Once it’s listed, you’ll also be able to add it from Connect apps.

Then

Tell the Bot “Help me launch my app” and give it a public GitHub URL — or try the sample.

Claude Code TERMINAL

$ claude mcp add aaplug2 -- npx -y aaplug2-mcp

Claude Desktop MAC · WINDOWS

  1. Settings→Developer→Edit Config, then add this to claude_desktop_config.json: 
    {
  "mcpServers": {
    "aaplug2": {
      "command": "npx",
      "args": ["-y", "aaplug2-mcp"]
    }
  }
}
  2. Fully quit Claude and open it again.

claude.ai WEB · MOBILE

  1. Customize→Connectors→Add custom connector
  2. Paste the public server address:
    https://…/mcpNot live yet

    The public address will appear here once the AA Plug 2 server is online. Until then, use the desktop option above — a cloud app can’t reach 127.0.0.1 on your computer.

Mac app LOCAL

  1. Install the PerplexityXPC helper first, as described in Perplexity Help.
  2. Plugins→Add custom, add an MCP connector with this command: 
    npx -y aaplug2-mcp

Web & other apps REMOTE

  1. Plugins→Add custom→Add MCP connector→Remote
  2. Name
    AA Plug 2
    URL
    https://…/mcpNot live yet
    Transport
    Streamable HTTP
    Authentication
    None

    The URL will appear here once the public server is online. Until then, use the Mac app.

mcp.json

  1. Add this to .cursor/mcp.json in your project, or to ~/.cursor/mcp.json for all projects: 
    {
  "mcpServers": {
    "aaplug2": {
      "command": "npx",
      "args": ["-y", "aaplug2-mcp"]
    }
  }
}
  2. Approve the server the first time Cursor asks.
→

After that, just talk to your AI. You only pick and approve. You press Submit yourself in Play Console or App Store Connect.

Needs Node.js 20+ for npx npm: aaplug2-mcp
